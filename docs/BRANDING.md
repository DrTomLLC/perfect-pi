# Perfectπ Branding

## Official names

- Public brand: **Perfectπ**
- Plain-text name: **Perfect Pi**
- Cargo package: `perfect-pi`
- Rust crate/import: `perfect_pi`
- Repository: `perfect-pi`

## Brand principles

The visual identity should communicate mathematical precision, engineering trust, efficiency, and broad scientific applicability without looking tied to Raspberry Pi hardware, food/pie imagery, cryptocurrency, or a single engineering field.

## Logo direction

An original logo is planned. It should remain recognizable at GitHub-avatar size, work in monochrome, and make the π identity unmistakable.

No generated logo asset has been committed yet.
