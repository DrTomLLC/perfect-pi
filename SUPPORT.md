# Support

Perfectπ is currently in architecture/pre-implementation status.

For design questions and general discussion, use GitHub Discussions.

For reproducible defects, use the issue templates. Numerical discrepancies should use the dedicated **Numerical / precision issue** template.

For security-sensitive reports, use GitHub private vulnerability reporting rather than a public issue.

Until a version is explicitly released, README examples and planned API names should be treated as design direction rather than compatibility guarantees.
