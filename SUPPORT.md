# Support

Perfectπ currently has a working pre-release Rust core with bounded precision, verified native conversions, and optional IEEE binary16/binary128 interchange adapters. It has not yet reached a public crate release or production-readiness claim.

For design questions and general discussion, use GitHub Discussions.

For reproducible defects, use the issue templates. Numerical discrepancies should use the dedicated **Numerical / precision issue** template.

For security-sensitive reports, use GitHub private vulnerability reporting rather than a public issue.

Until a version is explicitly released, the pre-release API and README examples may still change and should not be treated as compatibility guarantees.
