# Code of Conduct

Perfectπ welcomes technical collaboration from people with different backgrounds and levels of experience.

Contributors are expected to:

- discuss evidence and code rather than attack people;
- keep reviews technical and specific;
- disclose uncertainty instead of overstating claims;
- respect security-reporting boundaries;
- avoid harassment, discrimination, threats, or deliberate disruption.

Maintainers may remove content or restrict participation when behavior materially interferes with a safe, productive technical project.
